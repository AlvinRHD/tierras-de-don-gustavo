Aquí van las fotografías auténticas del parque. No uses fotografías de otros alojamientos.

Archivos esperados (WebP recomendado, alrededor de 1200–1600 píxeles de ancho):
- portada.webp
- cabana-a.webp
- cabana-b.webp
- bosque.webp
- paisaje.webp
- descanso.webp
- paseo.webp
- detalle.webp

Cuando estén cargadas, cambia `mostrarFotosReales` a `true` en src/datos.ts.
Si falta alguna imagen, el sitio mostrará automáticamente su ilustración de respaldo.
